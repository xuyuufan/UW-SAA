# Data attribution

The instance files and retrieval-probability data in this package are redistributed from Zhanluo Zhang, “Data for A data-driven approach to solving the container relocation problem with uncertainties,” Mendeley Data, version 3, DOI [10.17632/3j52cjrm52.3](https://doi.org/10.17632/3j52cjrm52.3), [dataset page](https://data.mendeley.com/datasets/3j52cjrm52/3), licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

The bundled source archive and extracted JSON inputs are included to make this evaluation reproducible. The package does not include the paper PDF.
