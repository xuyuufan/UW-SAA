## 实现和复现

[独立检查器](../../checks/independent_gp_main_review.py) 只导入 Python 标准库和 NumPy，直接读取原始 ZIP 内的 JSONL。它先重建完整样本矩阵及条件设计，再开始统计；发布 CSV 仅在独立估计完成后用于比较。

原分析器通过抽中的布局索引取值并求平均；本实现将每次抽样转换为“每个布局被抽中几次”的频次权重，用矩阵乘法汇总。每个布局先平均家族条件，再平均几何内布局，等权平均 21 个几何；SS、TW、DP 各自形成相对减少率后再等权平均。同一抽样权重用于两个策略臂、所有条件和两个指标。CLEAN、Overlay、Regime 单独报告。

抽样保持注册的 NumPy PCG64、10,000 次、seed `202610195903`，按几何和布局指纹排序。区间另用排序后显式线性插值计算，没有调用原分析器或其分位数函数。原始记录的完整性验证也由本实现直接完成。

在仓库根目录的 Python 3.12 环境安装公开运行依赖后，运行：

```bash
OPENBLAS_NUM_THREADS=1 python -B checks/independent_gp_main_review.py
```

输出 `PASS_INDEPENDENT_NUMERICAL_REVIEW`；新回执和逐字段差值默认写到忽略提交的 `work/`。检查器不会重跑 MAIN 或训练。已保存的本次证据包括：

- [核验回执](../../checks/gp_main_independent_review.json)：检查器 SHA-256、仓库基准提交、环境版本、输入与模型哈希、各项检查及差异上限。
- [逐字段比较表](../../checks/gp_main_independent_comparison.csv)：全部 894 个发布值、独立计算值、差值和容差。
- [检查器测试](../../checks/test_independent_gp_main_review.py)：手工可算的数值原语及样本设计检查。

原分析器的精确复现检查仍可运行 `python -B -m checks.verify_gp_results`。它与本次数值核验互为补充。

## 结论核对

主指标搬移次数的 SS/TW/DP 等权减少率为 **6.6274%**，95% CI **[6.3839%, 6.8688%]**，与报告的 6.63% 一致。

CLEAN 的减少率为 **−1.7412%**，95% CI **[−2.3578%, −1.1372%]**，即搬移增加 **1.74%**。该退化在表格和图中明确保留。GP-only 的 `.05/6` 下分位数约为 −2.4835%，不能表述为六求解器非劣性通过。

41 个条件中有 38 个点估计为正；逐项区间有 36 个完全大于 0，3 个完全小于 0。区间未作同时多重比较校正，这些计数仅是逐项描述。所有结论限定为冻结 GP 的 UWSAA 与 NATIVE20 比较，不表示新 GP 优于其他求解器，也不产生 MEAN6。

未发现需要修正发布数值或扩大轨迹重跑范围的异常。本次没有重跑原始轨迹或 GP 训练；公开包没有完整动作历史，因此本次数值核验不等于逐动作合法性重放。训练回执及布局分离检查也不能单独证明全部历史人工决策的先后顺序。Caserta 不用于依据本次结果重新选式、选视距或调参。

按项目负责人 2026-10-25 的决定，新 GP 的消融及 P0、多 K/LB1 对照不再补跑，其待补跑标记已撤下。取消这些实验不影响本次 MAIN 的核验结论。
